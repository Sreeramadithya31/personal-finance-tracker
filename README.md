# 💰 Personal Finance Tracker

A simple and user-friendly web-based Personal Finance Tracker designed to help users manage their income, expenses, transactions, and financial records efficiently.

## 🚀 Features

- Track income and expenses
- Add and manage transactions
- View current balance
- Select different currencies
- Choose transaction dates
- Edit and manage transactions
- Export transaction data
- User Login page
- User Sign-Up page
- Support/Query page
- Responsive and simple user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Feather Icons
- PDFMake
